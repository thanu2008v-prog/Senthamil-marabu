# செந்தமிழ் ஆக்கம்

திணை, உணர்வு, கூற்று, வடிவம் ஆகியவற்றைத் தேர்ந்தால், அவற்றுக்கு இயைந்த புதிய செந்தமிழ்ப் பாடலோ கட்டுரையோ உருவாகும். வெளிவருவது ஆக்கம் மட்டுமே.

**செயலி:** https://thanu2008v-prog.github.io/senthamil-aakkam/

## நிறுவல்

- **Android:** Chrome இல் மேற்படி முகவரியைத் திறந்து ⋮ → «முகப்புத் திரையில் சேர்» (அல்லது «செயலியை நிறுவு»).
- **iPhone:** Safari இல் திறந்து பகிர் → «முகப்புத் திரையில் சேர்».
- **கணினி:** Chrome / Edge முகவரிப் பட்டையில் உள்ள நிறுவல் குறி.

முதல் திறப்பில் «அமைப்பு — Claude இணைப்பு» பகுதியில் உங்கள் Anthropic API திறவுகோலை இட்டுச் «சேமி».

## இணையமின்றி

செயலி, எழுத்துரு, முந்தைய 30 ஆக்கங்கள் இணையமின்றியும் கிடைக்கும். புதிய ஆக்கத்துக்கு இணையம் வேண்டும்.

## தனியுரிமை

தனிச் சேவையகமோ கணக்கோ கண்காணிப்போ இல்லை. திறவுகோலும் ஆக்கங்களும் தொலைபேசியில் மட்டும். «ஆக்கு» தொட்டால் மட்டும் தேர்வுகள் api.anthropic.com க்கு நேரடியாகச் செல்லும். விவரம்: `thaniyurimai.html`.

## மூலம்

இக்களஞ்சியம் «செந்தமிழ் மரபு» நூல் களஞ்சியத்திலிருந்து (github.com/thanu2008v-prog/senthamil-marabu) `scripts/build_seyali.py` ஆல் உருவாக்கப்படுகிறது. திருத்தங்கள் அங்கேயே செய்யப்பட வேண்டும். திட்டம்: `THITTAM.md`.
