# செந்தமிழ் மரபு

தொல்காப்பிய நூற்பாக்கள் 1602 — எழுத்து 483, சொல் 463, பொருள் 656 — மூலம் ஒரு சொல்லும் மாற்றப்படாமல் (பொருள். 652). ஒவ்வொரு நூற்பாவுக்கும்:

- **காண்டிகை** — பொருள், ஏது, எடுத்துக்காட்டு (பொருள். 647, 648)
- **உரை** — விதி / விலக்கு (645), இயைபு (649), மறுதலைக் கடாஅ (650)
- **துணிவு** — ஒன்றே: நூலில் நேரடியாக / ஒருதலை அன்மை / நூலில் இல்லை (650)
- இறுதியில் **ஆய்வுகள்** பிற்சேர்க்கை

அளவுகோல் இந்நூல் ஒன்றே; நூல் தீர்க்காதது «ஒருதலை அன்மை» எனக் குறிக்கப்படுகிறது.

## செந்தமிழ் — ஒருங்கிணைந்த கணினிச் செயலி

Windows-இல் `run_ai.bat`-ஐ இருமுறை சொடுக்கினால் **செந்தமிழ்** செயலி உலாவியில் திறக்கும். ஒரே சாளரத்தில் **செந்தமிழ் AI** தாவலில் `ezhu.3`, `தேடு: நிலம்`, `மரம் + கிளை` போன்ற வினாக்களையும், **செந்தமிழ் ஆக்கம்** தாவலில் பாடல்/கட்டுரை உருவாக்கத்தையும் பயன்படுத்தலாம். இயல்பான வினாக்களுக்கு AI நூலில் பொருந்தும் நேரடிப் பகுதிகளையும் நூற்பா எண்ணையும் தேடிக் காட்டும்; அது புதிய இலக்கண விதிகளை உருவாக்காது. பொருத்தம் கிடைக்காவிட்டால் அதையும் தெளிவாகச் சொல்லும். இது நூலின் உள்ளடக்கத்தின் மீதான சொல்-பொருத்தத் தேடல்; மனித வாசிப்பை மாற்றாது. தமிழ் எழுத்துரு செயலியுடன் வழங்கப்படுகிறது.

புதிய பாடல் அல்லது கட்டுரை உருவாக்க இணையமும் பயனரின் Anthropic API திறவுகோலும் தேவை; அந்த திறவுகோல்/செலவு Anthropic கணக்குடன் தொடர்புடையது. `run_aakkam.bat` பழைய அணுகலுக்காகவே உள்ளது; அது இதே ஒருங்கிணைந்த செயலியையே திறக்கும்.

```python
import senthamil_marabu as sm
sm.pothu("ezhu.302")              # வகை, எழுவாய், நிபந்தனை, விளைவு, முறைமை, சான்று …
sm.maatteru_sangili("ezhu.289")   # ['ezhu.289', 'ezhu.274', 'ezhu.264', 'ezhu.221', 'ezhu.203']
from senthamil_marabu.punarchi import punar; punar("மண்", "குடம்", "வேற்றுமை")   # மட்குடம் — எழு. 302
from senthamil_marabu import en; en.peyar(625)["peyar"]                          # அறுநூற்று இருபத்தைந்து
```
