← செயலிக்குத் திரும்பு

தனியுரிமை

செந்தமிழ் ஆக்கம் உங்கள் தொலைபேசியிலேயே இயங்குகிறது. இதற்கெனத் தனிச் சேவையகம் இல்லை; கணக்கும் இல்லை; பயன்பாட்டுக் கண்காணிப்போ விளம்பரமோ இல்லை.

தொலைபேசியில் சேமிக்கப்படுவன

  • நீங்கள் இட்ட Anthropic API திறவுகோல்.
  • தேர்ந்த மாதிரி.
  • முந்தைய ஆக்கங்கள் (இறுதி 30).

இவை இச்செயலியின் உலாவிச் சேமிப்பில் மட்டும் இருக்கும்; வேறெங்கும் அனுப்பப்படுவதில்லை.

அனுப்பப்படுவன

«ஆக்கு» என்று தொட்டால் மட்டும், நீங்கள் தேர்ந்தவையும் எழுதிய குறிப்பும் உங்கள் திறவுகோலோடு api.anthropic.com க்கு நேரடியாக அனுப்பப்படும். அவ்விடத்தில் அவை Anthropic நிறுவனத்தின் விதிகளின்படி கையாளப்படும். வேறு எந்த முகவரிக்கும் இச்செயலி எதையும் அனுப்புவதில்லை.

நீக்குதல்

  • திறவுகோல்: «அமைப்பு — Claude இணைப்பு» → «நீக்கு».
  • முந்தைய ஆக்கங்கள்: «முந்தைய ஆக்கங்கள்» → «எல்லாவற்றையும் அழி».
  • எல்லாம்: செயலியை நீக்கினால் அல்லது உலாவியில் இத்தளத்தின் தரவை அழித்தால், மேற்படி யாவும் நீங்கும்.

கட்டணம்

ஆக்கத்துக்கான கட்டணம் உங்கள் Anthropic கணக்கில் நேரடியாக வசூலிக்கப்படும். இச்செயலி கட்டணம் எதுவும் பெறுவதில்லை.
